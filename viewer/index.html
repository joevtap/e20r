e20r state viewer

Explore what the e20r pipeline learned about Effect adoption in TypeScript repositories. Everything runs locally in your browser — files are never uploaded.

Drop the pipeline's .jsonl files here, or use the picker. Load any mix, in any order — the page derives everything else.

What each file reveals

The pipeline writes one JSONL state file per stage. Each answers different questions — load the ones you care about, or all of them together:

repos.jsonl the crawl

Every repository the GitHub crawl saw: stars, forks, activity, language.

Answers: what is the population we looked at?

clone-state.jsonl the selection

Per repository: clone outcome, manifest signals (Effect versions, package managers) and the adopter decision.

Answers: which repos use Effect at all, and how is it declared?

effect-repos.jsonl the hand-off

Adopters handed to deep analysis, each pinned to the exact commit that was analyzed.

Answers: which repositories got the deep dive?

analysis-state.jsonl the usage

Per adopter: TypeScript file inventory, Effect imports per file, packages used, and AST symbol usage (calls, types, property accesses).

Answers: how deeply is Effect actually used in the code?

run-summary.jsonl the population

One snapshot per run: repos analysed, adopters, and the resulting ratios.

Answers: out of the analysed repos, how many use Effect — and how does that trend?

Records are appended across runs; where it matters, this page counts each repository once (latest record wins), like the pipeline itself. Unknown record shapes and signal tags still show up as raw JSON — newer pipelines never break this page.
